## Findings considered and rejected

- **`pageIndex` springs back to a previously written page when a filter is
  cleared**: by design — `pageIndex` stores the written value and clamps on
  read; the v7 migration guide documents it.
- **Make `canExpand` a `ReadonlyBox<boolean>`**: rejected for v7.0 — same
  observable result as the accessor in plan 002 at the cost of changing the
  route helpers, five docs demos and the guide; candidate for the next major.
- **Server-side recomputation of the derivation chain for view models built
  outside a render**: real, not a regression from v6, and larger than a
  review fix; planned separately in `.agents/.plans/ssr-derivation-cost/`.
